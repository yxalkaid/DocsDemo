# 快速开始

这是一个 **示例页面**，用于测试 [VitePress](https://vitepress.dev/) 的基本功能。

## 功能演示

### 代码高亮

VitePress 支持多种语言的代码高亮，例如 Python：

```python
def hello(name: str) -> str:
    return f"你好，{name}！"

print(hello("VitePress"))
```

以及 JavaScript：

```js
console.log('Hello from VitePress!');
```

### 列表

- 支持无序列表
- 自动渲染 Markdown
- 响应式设计

1. 也支持有序列表
2. 适合写技术文档
3. 构建速度快
